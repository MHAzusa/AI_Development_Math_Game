# 要件定義書

## 1. システム概要

### 1.1 システム名

計算ゲーム

### 1.2 目的

計算問題をゲーム形式で解くことができるシステムを開発する。

本システムは個人学習を目的としている。

また、システム開発者自身のソフトウェア開発学習も目的とする。

## 2. 利用者

現時点では、個人での利用を想定する。

詳細な利用者像については未確定。

## 3. システムの目的

本システムでは、ユーザーが計算問題を解き、その結果を確認できることを基本的な目的とする。

計算問題をゲーム形式で繰り返し解くことで、計算学習に利用できることを目指す。

## 4. 必須要件

### REQ-001
ユーザーが計算問題に挑戦できること。

### REQ-002
ユーザーが計算問題に対する回答をキーボードで入力できること。

### REQ-003
ユーザーの回答が正解か不正解か判定できること。

### REQ-004
10問の問題に回答した後、結果を確認できること。

### REQ-005
1ゲームは10問で構成されること。

### REQ-006
計算問題は四則演算および括弧を使用すること。

### REQ-007
難易度はEasy、Normal、Hardの3段階とすること。

### REQ-008
数値範囲などの問題の難しさは難易度によって変更すること。

### REQ-009
割り算では小数の答えを許可すること。

### REQ-010
小数の答えを扱う場合、有限小数になる問題のみ出題すること。

### REQ-011
負の数を使用する問題を出題できること。

### REQ-012
スコアは設定せず、ゲーム結果として正解数、正答率、10問の総回答時間を表示・保存すること。

### REQ-013
10問目の回答が完了した時点でゲームを終了すること。

### REQ-014
問題に回答した後は直ちに次の問題へ進み、各問題の正解・回答内容はゲーム終了後に確認できること。

### REQ-015
ゲーム開始時にユーザーがEasy、Normal、Hardから難易度を選択できること。

### REQ-016
総回答時間はゲーム開始時点から10問目の回答完了時点までの時間とすること。

### REQ-017
ゲーム終了後の結果として、ゲームの難易度、正解数、正答率、10問の総回答時間、および各問題の問題内容・ユーザーの回答・正解・正誤を保存すること。

### REQ-018
回答はEnterキーを押すことで確定すること。

### REQ-019
Enterキーを押すまでは、入力した回答を自由に修正できること。

### REQ-020
回答として数値として認識できない入力は確定できないこと。

### REQ-021
回答判定では、数値として同じ値であれば正解とすること。

### REQ-022
正答率はパーセント形式で表示すること。

### REQ-023
総回答時間は秒単位で表示すること。

### REQ-024
ゲーム開始は、難易度を選択した後に「ゲーム開始」操作を行った時点とすること。

### REQ-025
回答入力では、一般的な整数・小数・負数を入力可能とする。細かな入力形式については仕様・設計で決定する。

### REQ-026
ゲーム終了後の結果では、各問題について問題、ユーザーの回答、正解、正誤を確認できること。

### REQ-027
ゲーム途中で終了・離脱した場合、そのゲームの結果は保存しないこと。

### REQ-028
ゲーム結果は、1ゲームにつき1つの記録として保存すること。

### REQ-029
保存したゲーム結果を後から閲覧する機能は、初期バージョンでは提供しないこと。

### REQ-030
対応するデバイスはPCとすること。

### REQ-031
保存したゲーム結果には保存期間を設けないこと。

### REQ-032
初期バージョンでは、保存したゲーム結果を後から閲覧する機能を提供しないこと。

### REQ-033
初期バージョンでは、ユーザー認証を行わないこと。

### REQ-034
ゲーム途中でブラウザを閉じる、ページを再読み込みする、別ページへ移動するなど、ゲームを離脱した場合は、そのゲームを未完了として扱い、結果を保存しないこと。

### REQ-035
対応するブラウザは主要なPC向けWebブラウザとすること。

## 5. 成績保存要件

ゲームが正常に終了した場合、1ゲームにつき1つの記録として、以下の情報を保存する。

- ゲームの難易度
- 正解数
- 正答率
- 10問の総回答時間
- 各問題の問題内容
- 各問題に対するユーザーの回答
- 各問題の正解
- 各問題の正誤

ゲーム途中で終了・離脱した場合は、そのゲームの結果を保存しない。

保存したゲーム結果を後から閲覧する機能は、初期バージョンでは提供しない。
